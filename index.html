01 · 개념 · 교과서 118~119쪽

선형 회귀란 무엇일까?

두 친구의 대화를 먼저 살펴봅시다. 우리는 이미 일상에서 "회귀적으로" 생각하고 있었을지도 몰라요.

이번에 빌린 판타지 소설 1권, 300쪽쯤 됐는데 3시간 만에 다 읽었어!
오, 꽤 빨리 읽었네. 그렇게 재밌었어?
완전. 근데 2권은 450쪽이나 되더라고. 이것도 다 읽으려면 얼마나 걸릴까?
쪽수가 더 많으니까 3시간보다는 오래 걸리지 않을까?

친구는 쪽수가 늘어나면 독서 시간도 늘어날 것이라 예측했습니다. 이렇게 두 속성 사이에 선 모양의 관계가 있다고 가정하고, 데이터를 가장 잘 대표하는 선을 찾는 분석 방법을 교과서는 다음과 같이 정의합니다.

📖 교과서 원문『데이터 과학』 119쪽

"선형 회귀는 두 가지 이상의 속성 사이에 선 모양의 관계가 있다고 가정하고 데이터를 가장 잘 대표하는 선을 찾는 분석 방법이다."

이때 예측하려는 값(독서 시간)을 종속 변수, 예측에 사용하는 값(쪽수)을 독립 변수라고 하며, 이 둘의 관계를 가장 잘 나타내는 선을 회귀선이라 부릅니다. 독립 변수가 하나뿐인 선형 회귀는 단순 선형 회귀라고 합니다.

y=ax+b
a — 가중치 (기울기)x가 1 커질 때 y가 얼마나 커지는지, 즉 독립 변수가 종속 변수에 미치는 영향력의 크기입니다.
b — 편향 (절편)x가 0일 때 y의 값. 독립 변수와 무관하게 항상 더해지는 값입니다.

a와 b처럼 회귀 모델에서 구하고자 하는 값을 회귀 계수라고 합니다. 최적의 a, b를 구하면 회귀선이 완성됩니다.

‘회귀’라는 용어의 유래. 프랜시스 골턴(Francis Galton)은 부모와 자식의 키 사이 관계를 연구하며 ‘회귀’라는 말을 처음 사용했습니다. 부모의 키가 아무리 크거나 작아도, 자녀의 키는 그 세대의 평균값으로 돌아가려는 경향을 보였기 때문입니다.
🏺 역사 속 회귀 분석 — 문종과 측우기 (118쪽)

조선 시대에는 날씨를 예측하는 기술이 없어 가뭄이나 홍수가 들면 그 해 농사를 그르치고 백성들이 굶주렸습니다. 이에 문종은 빗물의 양을 꾸준히 재서 기록으로 남겨 두면, 그 자료를 바탕으로 앞으로 내릴 비의 양을 미리 가늠할 수 있으리라 생각했습니다.

그 결과 탄생한 것이 측우기입니다. 지름 약 23.31cm의 둥근 통을 전국에 설치해 동일한 조건에서 정기적으로 강수량을 기록했습니다. 「승정원일기」에 남은 이 기록 덕분에 우리나라는 1653년, 1777년, 1901년처럼 약 124년을 주기로 큰 가뭄이 온다는 사실을 알아내, 가뭄에 미리 대비할 수 있었습니다. 데이터를 축적해 미래를 예측한, 아주 오래된 회귀 분석의 사례입니다.

03 · 두 가지 회귀 모델 · 교과서 120~127쪽

최적의 선, 어떻게 찾을까?

최적의 가중치와 편향을 구하는 방법에는 두 가지가 있습니다. 하나는 수식을 풀어 한 번에 계산하는 방법, 다른 하나는 컴퓨터가 조금씩 값을 보정해 나가는 방법입니다.

통계적 회귀 모델

수식을 풀어 한 번에 계산

오차 제곱의 총합을 최소로 만드는 a, b를 수학적으로 계산합니다. 독립 변수가 하나인 경우 다음 공식으로 바로 구할 수 있습니다.

a = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)²
b = ȳ − a·x̄

인공지능 이전부터 쓰여온, 통계학에 기반한 방법입니다. (120~121쪽)

기계학습 기반 회귀 모델

조금씩 보정하며 다가가기

데이터를 하나씩 학습하며 예측값과 실젯값의 오차가 클 땐 많이, 작을 땐 조금씩 회귀 계수를 보정합니다. 이 방법을 경사 하강법이라 부릅니다.

평균제곱오차(MSE)가 최소가 되는 지점을 향해 항아리 모양의 그래프를 따라 내려갑니다. (124~125쪽)

🖐️ 손으로 확인해보기 — 공식에 값 대입하기 (교과서 121쪽과 같은 활동, 선택)

시간이 부족하면 직접 계산하지 않아도 됩니다. 아래 단계를 하나씩 눌러 과정만 확인해도 충분합니다. 실험 절에서 쓴 데이터 (150,70), (200,100), (270,125), (320,155), (380,170)를 그대로 공식에 넣어 계산해 봅니다.

1단계 — 평균 구하기

x̄ = (150+200+270+320+380) ÷ 5 = 264

ȳ = (70+100+125+155+170) ÷ 5 = 124

2단계 — 편차와 편차의 곱 구하기

각 점에서 x−x̄와 y−ȳ를 구하고, 둘을 곱합니다.

xyx−x̄y−ȳ(x−x̄)(y−ȳ)(x−x̄)²

3단계 — 각 열의 합 구하기

Σ(x−x̄)(y−ȳ) = 6156+1536+6+1736+5336 = 14770

Σ(x−x̄)² = 12996+4096+36+3136+13456 = 33720

4단계 — a, b 계산하고 확인하기

a = 14770 ÷ 33720 ≈ 0.44

b = 124 − 0.44 × 264 ≈ 8.4

즉 이 데이터에 가장 잘 맞는 회귀선은 y ≈ 0.44x + 8.4 입니다. 실험 절에서 🏆 최적의 회귀선 비교해 보기 버튼을 눌렀을 때 그래프에 나온 식과 같은지 확인해 보세요. 버튼 하나가 순식간에 해 준 계산을, 우리는 방금 손으로 따라가 본 것입니다.

    선생님 확인용 예시 코드

    main.py와 requirements.txt, 두 파일로 저장합니다. 인터넷에서 데이터를 내려받지 않는 자체완결형 앱이라 어떤 환경에서도 바로 실행됩니다.

    main.py
    import streamlit as st
import numpy as np
import plotly.express as px
import pandas as pd

st.title("독서 시간 회귀선 실험실")

x = np.array([150, 200, 270, 320, 380])
y = np.array([70, 100, 125, 155, 170])

a = st.slider("가중치 a", 0.0, 0.6, 0.2, 0.01)
b = st.slider("편향 b", 0, 100, 50)

pred = a * x + b
sse = float(np.sum((y - pred) ** 2))

df = pd.DataFrame({"쪽수": x, "독서 시간": y})
fig = px.scatter(df, x="쪽수", y="독서 시간")
fig.add_scatter(x=x, y=pred, mode="lines", name="내 회귀선")
st.plotly_chart(fig, width="stretch")

st.metric("오차 제곱합 (내 직선)", f"{sse:.1f}")

a_best, b_best = np.polyfit(x, y, 1)
sse_best = float(np.sum((y - (a_best * x + b_best)) ** 2))
st.metric("오차 제곱합 (통계적으로 가장 잘 맞는 직선)", f"{sse_best:.1f}")
st.caption(f"최적의 회귀선: y = {a_best:.2f}x + {b_best:.1f}")

    ③ 개선 프롬프트
    버튼 두 개를 추가해 줘. 하나는 눌렀을 때 a=0.2, b=50으로,
다른 하나는 a=0.3, b=40으로 슬라이더 값이 바로 바뀌게 해 줘.
두 경우의 오차 제곱합을 각각 계산해서 어느 쪽이 더 작은지,
그래서 어느 직선이 더 좋은 예측 모델인지 문장으로 알려 줘.

    이 결과를 위쪽 실험 절에서 직접 조절해 본 값과 비교해 보세요. 같은 결론에 도달하나요?

같은 답, 두 가지 방법. 앱 안의 "통계적으로 가장 잘 맞는 직선"은 수식을 한 번에 풀어 계산한 것이고(통계적 회귀 모델), 슬라이더로 값을 조금씩 바꿔가며 오차를 줄여 나간 것은 기계학습이 경사 하강법으로 하는 일을 손으로 흉내 낸 것입니다. 방식은 다르지만 결국 같은 결론, 즉 오차가 가장 작은 직선을 향해 갑니다.

선형 회귀는 y = ax + b 형태로 데이터를 가장 잘 대표하는 회귀선을 찾는 분석 방법이며, 독립 변수가 하나면 단순 선형 회귀라고 한다.

02

실젯값과 예측값의 차이인 오차를 제곱해 합한 값이 작을수록 더 좋은 회귀선이다.

03

통계적 회귀 모델은 수식을 풀어 회귀 계수를 한 번에 계산하고, 기계학습 기반 회귀 모델은 경사 하강법으로 계수를 조금씩 보정해 최적값에 접근한다.
