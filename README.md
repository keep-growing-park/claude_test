# 선형 회귀 실험실

고등학교 2학년 데이터 과학 수업용 온라인 콘텐츠입니다. 교과서 「Ⅲ. 데이터 모델링과 평가 — 02. 회귀 분석」(118~127쪽)의 선형 회귀 부분을 학생이 교과서와 나란히 펴 놓고 볼 수 있도록 만들었습니다.

- 개념 설명 + 교과서 원문 인용(쪽수 포함)
- 가중치·편향을 직접 조절하며 오차를 비교하는 인터랙티브 실험
- 통계적 회귀 모델 vs 기계학습 기반 회귀 모델 비교
- 파이썬을 직접 타이핑하는 대신, AI에게 프롬프트로 요청해 스트림릿 앱을 만드는 바이브 코딩 실습

`index.html` 하나로 이루어진 정적 페이지입니다. 저장소 설정에서 GitHub Pages를 켜면(Settings → Pages → Branch: 배포할 브랜치 선택) 별도 빌드 없이 바로 온라인으로 열람할 수 있습니다.
